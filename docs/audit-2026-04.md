## 6. Mobile "still feels simple" check

- The original Swift app had 2 user-facing view controllers
  (Main + Preview) plus a Help screen.
- The new Expo app has 9 user-facing screens:
  1. `index.tsx` — splash / start
  2. `(camera)/index.tsx` — camera + countdown
  3. `(camera)/preview.tsx` — preview + print
  4. `(camera)/paywall.tsx` — Event Pass paywall (modal, only when host
     hits paywall)
  5. `(camera)/strip-unlock.tsx` — Strip Unlock (modal, only when user
     taps watermark)
  6. `(tabs)/event.tsx` — Connect to event (host-only)
  7. `(tabs)/settings.tsx` — Settings (3 controls + about + account)
  8. `(tabs)/help.tsx` — Help + setup instructions
  9. `(tabs)/privacy.tsx` — Privacy info screen
- Settings screen has only 3 controls: flash default, layout default,
  QA preview override. Plus an About section and (when signed in) an
  Account section. That is not a 30-setting kitchen sink.
- The core flow (open -> take photos -> print) traverses just 3 screens
  (index -> camera -> preview). Same as the original.
- Verdict: passes the simplicity bar. The extra screens only appear when
  the user opts into something (event, settings, paywall).

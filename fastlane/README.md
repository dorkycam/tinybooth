# Fastlane lanes for TinyBooth iOS

Fastlane handles the App Store metadata and screenshot pipeline for the iOS
TinyBooth app. EAS handles the binary build and submit. The two stay in sync
because both reference the same env vars (`APPLE_ID`, `APPLE_TEAM_ID`,
`APP_IDENTIFIER`).

## One-time setup

Install Bundler and the pinned Fastlane version:

```sh
cd apps/mobile
gem install bundler -v 2.5.9
bundle install
```

Copy the env template and fill in real values:

```sh
cp fastlane/.env.example fastlane/.env
$EDITOR fastlane/.env
```

If you are using the App Store Connect API key (recommended for any
non-interactive run), drop the `.p8` file at `apps/mobile/secrets/asc-api-key.p8`
and set the three `ASC_API_*` env vars in `fastlane/.env`.

## Lanes

```sh
bundle exec fastlane metadata_pull       # fetch the live App Store listing
bundle exec fastlane metadata_push       # push fastlane/metadata/ back up
bundle exec fastlane screenshots         # capture + frameit
bundle exec fastlane screenshots_push    # upload only screenshots
```

What each lane does:

- `metadata_pull` runs `deliver download_metadata`. Useful right after
  Camrynn edits the App Store Connect listing by hand and wants to commit the
  change back to git.
- `metadata_push` runs `deliver` with `--skip_binary_upload --skip_screenshots`.
  Pushes only the contents of `fastlane/metadata/`. Never submits for review.
- `screenshots` runs `snapshot` against the `TinyBoothUITests` UI test target
  in `ios/TinyBoothUITests/`, then `frameit` to add device frames. Output
  lands in `fastlane/screenshots/<lang>/<device>/`. Devices listed in
  `Snapfile` (iPad Pro 12.9", iPhone 15 Pro Max, iPhone 11).
- `screenshots_push` runs `deliver` with `--skip_metadata --skip_binary_upload`.
  Uploads only the framed screenshots.

## What lives where

- `Appfile` - app id, Apple ID, team id (all read from env).
- `Deliverfile` - safety defaults for `fastlane deliver`.
- `Snapfile` - device matrix and output directory for `fastlane snapshot`.
- `Pluginfile` - declared plugins (versioning).
- `Fastfile` - the four lanes above.
- `metadata/en-US/` - the App Store listing copy. Edit by hand or via
  `metadata_pull`; push with `metadata_push`.
- `screenshots/` - generated by `snapshot`. Gitignored.
- `.env`, `.env.*` - your secrets. Gitignored.

## EAS overlap

EAS owns the binary build + submit (`eas build`, `eas submit`). Fastlane only
touches metadata and screenshots. The `fastlane/` directory does not need to
exist for `eas build` to work; it exists for the App Store Connect side of
the listing.

## Hard rules

- No lane uploads a binary.
- No lane submits for review.
- No lane logs secrets.
- Real credentials live in `fastlane/.env` (gitignored) and never in the
  Fastfile or Appfile.
